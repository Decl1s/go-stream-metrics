# Фактические проверки

17 октября 2026 года, Linux amd64, Go 1.27.2, Python 3.12.3.
Пройдены 22 верхнеуровневые тестовые функции Go; в одной из них дополнительно
проверяются 21 вариант неверной строки. go vet ./... ошибок не сообщил.
Также прошли 3 теста публикации. Исходный ZIP распакован в отдельную временную
папку: повторно прошли 22 функции Go, go vet, 3 теста публикации, сборка и smoke.
Архив содержит ровно 21 файл из PUBLIC_FILES.txt; байты сверены с исходниками.

Собран исполняемый файл и выполнено стандартное демо: 10 005 входных строк,
10 000 принятых, 5 ошибочных, 3 сервиса. Проверены 500 ответов 5xx, 300 ответов 4xx,
5010 медленных запросов при пороге 500 мс; все сервисы имеют p95_upper_ms = 1000.
JSON stdout совпадает с сохранённым результатом. Повтор идентичен.
Повторное сохранение в существующий результат отклоняется, файл сохраняет свои байты.

Проверены границы всех десяти интервалов, ручной пример 100/200/300 мс,
дубликаты как отдельные события, неверный UTF-8, повтор ключа, null, bool, строки,
дроби и экспоненты вместо целых чисел. Проверены ограничения строки, числа строк,
байтов и сервисов, ошибка Reader без частичного результата и очистка при ошибке записи.
Отдельный Reader формирует 100 000 строк без хранения всего набора и запрещает
запросы чтения блоками больше установленного предела.

## Одноразовый замер памяти

Один и тот же собранный инструмент запущен через /usr/bin/time -f '%M' на двух
синтетических файлах, с теми же тремя сервисами и параметрами.

| Вход | Размер, байт | Принято | Максимальный RSS, КиБ |
| --- | --- | --- | --- |
| Малый | 512 475 | 10 000 | 8668 |
| Большой | 51 226 545 | 1 000 000 | 10176 |

В каждом файле дополнительно 5 ошибочных строк; большой полностью обработан.
Это наблюдение одного запуска на Linux, не гарантия предела памяти и не нагрузочный тест.
Память не обязана совпадать между запусками: влияют среда исполнения и управление памятью.
Байты выделений за всё время не использовались как замена пиковой памяти.

## Публикация и ограничения

CI подготовлен для Ubuntu и Windows с Go 1.27.2 и Python 3.12.
Исходники и релиз GitHub не опубликованы, CI не запущен: повторные попытки
открыть GitHub завершились ERR_CONNECTION_CLOSED, подключение GitHub вернуло
ошибку транспорта. Создание репозитория и загрузка файлов не выполнялись.
Готовый проверенный архив сохранён локально для последующей публикации.

Дополнительно на Linux успешно выполнена кросс-сборка Windows/amd64 с CGO_ENABLED=0.
Запуск и тесты на Windows не выполнялись; кросс-сборка их не заменяет.

Не проверялись максимальный вход 2 ГиБ, 100 млн строк, все 1024 сервиса одновременно,
авария питания, принудительное завершение при записи и изменения входа другим процессом.
Аудит безопасности, точный перцентиль и обработка настоящих рабочих журналов не выполнялись.

Перед коммитом исправлено слишком широкое правило .gitignore, исключавшее каталог
cmd/streammetrics. Все 21 исходный файл проверены на отсутствие игнорирования;
список отслеживаемых файлов должен точно совпадать с PUBLIC_FILES.txt.
